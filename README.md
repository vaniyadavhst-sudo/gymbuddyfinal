# 💪 Gym Buddy

**Gym Buddy** is a smart and user-friendly fitness tracking web application that helps users manage their workout routines, track progress, and stay consistent with their fitness goals.

---

## 🚀 Features

* 🔐 **User Authentication**

  * Login & Signup functionality
  * Personalized user dashboard

* 📊 **Workout Tracker**

  * Track daily and weekly workouts
  * Monitor sets, reps, and calories burned
  * View workout consistency and streaks

* 🤖 **AI Workout Planner**

  * Personalized workout recommendations
  * Daily & weekly workout plans
  * Based on user goals (weight loss, muscle gain, maintenance)

* 🥗 **Diet & Nutrition**

  * AI-based meal recommendations
  * Protein, calories, carbs & fats breakdown
  * Indian diet options included

* 🩸 **Women’s Health Section**

  * Special workout suggestions during periods
  * Light exercises, yoga & recovery tips

* 📜 **History Tracking**

  * View past workouts
  * Weekly and monthly logs

* 💧 **Extra Features**

  * Water intake tracker
  * Step counter (manual input)
  * Daily motivational quotes

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/your-username/gymbuddyfinal.git
```

2. Navigate to project folder:

```
cd gymbuddyfinal
```

3. Install dependencies:

```
npm install
```

4. Run the project:

```
npm run dev
```

5. Open in browser:

```
http://localhost:5173/
```
